# Inventory Management System using Python Flask

## Description
A web-based Inventory Management System developed using Python Flask with CRUD operations, authentication, and SQLite database.

## Features
- User Login Authentication
- Add, Edit, Delete inventory items
- View inventory list
- Low stock indication
- SQLite database integration
- Simple and user-friendly UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Jinja2

## How to Run the Project
1. Install Python
2. Install Flask:
   pip install flask
3. Run the application:
   python app.py
4. Open browser and go to:
   http://127.0.0.1:5000/
