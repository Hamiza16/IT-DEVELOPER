**Inventory Management System (Flask)**

A web-based Inventory Management System built using Python (Flask) and SQLite.
The system helps administrators manage stock, track quantities, and generate
 downloadable reports — all through a clean and user-friendly interface.


**Key Features**

- ***Secure User Login (Session-based Authentication)*** 
  Only authorized users can access and manage the inventory.

- ***Add, Edit & Delete Items*** 
  Maintain product records easily with real-time updates.

- ***Smart Search*** 
  Quickly find items by name.

- ***Advanced Sorting***  
  Sort inventory by:
  - Name  
  - Quantity  
  - Price  

- ***CSV Export (Download Reports)***  
  Download inventory reports with one click.

- ***Delete Confirmation Dialog*** 
  Prevents accidental deletion.

- ***Success Alerts***  
  Clear messages after Add, Update, Delete, and Logout actions.

- ***Pagination Support***  
  Handles large inventory lists smoothly.

- ***Dashboard Overview***  
  Quick summary view for monitoring inventory.

**How to Run the Project**

1. Install Python.
2. Install Flask:`pip install flask`
3. Run the application: `python app.py`
4. Open browser and go to: `http://127.0.0.1:5000/`
